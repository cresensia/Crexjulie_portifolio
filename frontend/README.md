# Cresensia Julius Portfolio - Frontend

##  Overview
This is the *frontend* for the Cresensia Julius Portfolio project.  
It is a static website built with *HTML, CSS, and JavaScript*, showcasing:
- Personal profile
- Skills & qualifications
- Projects
- Contact form (connected to backend API)
- API status check (on the Core Competencies page)

The frontend is deployed on *Vercel*.

##  Tech Stack
- *HTML5* → Structure
- *CSS3* → Styling and animations
- *JavaScript (ES6)* → Form handling and API integration
- *Hosting:* Vercel
## Backend Integration
- The contact form sends data to the backend API
- The API status widget checks the backend health endpoint
- Backend hosting is expected on Render
